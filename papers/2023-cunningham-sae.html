Sparse Autoencoders Find Highly Interpretable Features in Language Models

稀疏自編碼器可在語言模型中找到高度可解讀的特徵

Authors & AffiliationHoagy Cunningham, Aidan Ewart, Logan Riggs, Robert Huben, Lee Sharkey · EleutherAI, MATS, Bristol AI Safety Centre, Apollo Research
Venue & YeararXiv 2023

核心價值：使用 Sparse Autoencoder 從語言模型內部 activation 學習 overcomplete、稀疏啟動的 feature dictionary，嘗試把 superposition 中混雜的特徵拆成更可理解的方向。

主要貢獻：

  1. 以 reconstruction loss 搭配 L1 sparsity penalty 學習 feature dictionary。
  2. 透過 autointerpretability、monosemantic case study 與 activation patching 驗證特徵可解讀性與因果作用。
  3. 展示 dictionary features 可用於精細 IOI 行為定位與自動 circuit detection。

研究痛點：神經元常具有 polysemanticity，同一神經元可能在語義不同情境中啟動；residual stream 等空間中的特徵不一定對齊 neuron basis。

核心洞察 (Key Insight)：Polysemanticity 可能源於 superposition：模型以 overcomplete、非正交方向表示多於維度的特徵。稀疏啟動時，可透過 sparse dictionary learning 從 activation 重建中找到方向。

  1. 抽取 residual stream、MLP sublayer 或 attention head sublayer 的內部 activation。
  2. 訓練單層 Sparse Autoencoder：encoder／decoder 使用 tied weights，hidden size 由模型維度與 dictionary size ratio 決定，並以 ReLU 產生係數。
  3. 同時最佳化 reconstruction loss 與 L1 sparsity loss，鼓勵少量 feature 線性組合重建 activation。
  4. 用 autointerpretability 描述 feature，再以新文本預測啟動程度；用 activation patching 評估 feature 的因果效果。

評估基準：Pythia-70M 與 Pythia-410M；比較 neuron/default basis、random directions、PCA 與 ICA；並在 IOI 反事實句子上進行 activation patching。

關鍵發現：

  • Dictionary features 的 autointerpretability 整體優於多種 baseline，但效果在較後層下降。
  • 個別 feature 可只對 apostrophe、period、`the` 或 newline 等模式啟動，呈現 highly monosemantic 特徵。
  • 在 IOI activation patching 中，sparse dictionaries 能以較少 patches 達成相同 KL divergence，並改善 edit magnitude 與 editing thoroughness 的權衡。
  • 跨層 feature 消融可建立 causal tree，用於自動 circuit detection。

侷限性：SAE reconstruction 無法達到 zero loss；較高 sparsity 可能降低 reconstruction accuracy；現有訓練管線最適合 residual stream，在 attention head 與 MLP 上仍有挑戰；自動解讀也不必然完整描述後層複雜特徵。

未來展望：探索其他 SAE 架構、加入相鄰層與模型權重資訊、直接優化輸出變化；發展更穩健的 MLP 與 attention head training；追蹤跨層 feature causal dependencies。

延續 Yun et al. 與 Sharkey et al. 的 sparse dictionary learning 工作，也與視覺皮質 sparse dictionary learning 相關。

相較於 neuron basis、PCA、ICA 與 random/default directions，SAE 透過 learned overcomplete dictionary 與 sparsity penalty 尋找可能對應單一語義的 activation directions。

研究省思：SAE 提供從任意 internal direction 進到更 monosemantic feature dictionary 的方法，可與 RepE 的 representation reading 和 direction control 串接。

研究切入點：下一步值得區分 SAE feature 是否真實對應可泛化的網路概念，而不只是特定資料與 token 分布下的稀疏分解。
